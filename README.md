# fang89

Small tools and one-page guides, mostly about Singapore and Neopets. Most of them run in the browser with nothing to install.

<sub>[all Singapore repos](https://github.com/fang89?tab=repositories&q=topic%3Asingapore)</sub>

| Project | What it is | |
|---|---|---|

| **ATMs** | How far every HDB block is from the nearest DBS/POSB ATM | [Open](https://fang89.github.io/Singapore-ATMs/) · [Repo](https://github.com/fang89/Singapore-ATMs) |
| **STI** | 38 years of the STI and its 30 constituents since 1987, annotated | [Open](https://fang89.github.io/Singapore-STI/) · [Repo](https://github.com/fang89/Singapore-STI) |
| **Personal finance** | A one-page guide: CPF, Irish-domiciled ETFs via IBKR, one cashback card | [Open](https://fang89.github.io/Singapore-personal-finance/) · [Repo](https://github.com/fang89/Singapore-personal-finance) |
